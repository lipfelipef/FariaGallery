Este arquivo existe só para documentar o formato. Enquanto `rascunho` for
`true`, ele fica no repositório e **não** entra no site nem no RSS.

O nome do arquivo vira o endereço do post. `primeiro-post.md` fica em
`/blog/primeiro-post`, então vale escolher um nome curto, sem acento e sem
espaço, porque endereço de post não se troca depois sem quebrar link de quem
já compartilhou.

## O que dá para usar

Título de seção, **negrito**, _itálico_, [link](https://fariagallery.com),
lista:

- primeiro item
- segundo item

Bloco de código com a linguagem declarada:

```ts
const oi = 'mundo';
```

E citação:

> Texto citado.
